# Sales Hub

Lightweight account-expansion and sales execution tool.

## First version
- Sales manager dashboard
- Customer expansion checklist
- Expandable "How to do it" guidance for every checklist item
- Comment/evidence field for every checklist item
- Opportunities with stage, owner, next action and date
- Field intelligence capture
- Marketing ideas and execution tracker

## Data
The prototype stores data in the browser using localStorage. This is intentional for the first test version. A shared database and login should be the next step before wider team use.

## GitHub Pages
Publish the repository from the main branch root in Settings -> Pages to use the site as a web app.
